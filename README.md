# Product Description Skill for Claude (free)

A free skill that makes Claude write **conversion-focused product descriptions** for Shopify and other online stores: benefits before features, scannable bullets, clean Shopify-ready HTML, SEO-friendly wording – and it never invents product facts.

## Example
**You:** *Handmade ceramic mug, 350 ml, stoneware, dishwasher safe, speckled glaze, made in Portugal. Write a product description.*

**Claude** returns a hook, 3 benefit bullets, a short story paragraph and a specs list as HTML you can paste straight into the Shopify editor. See the full example in [`store-product-description/SKILL.md`](store-product-description/SKILL.md).

## Install
- **Claude.ai:** download `store-product-description.zip` and upload it in **Settings → Features** (needs a plan with custom skills and code execution enabled).
- **Claude Code:** copy the `store-product-description` folder into `~/.claude/skills/`.

Then just ask Claude to write a product description.
